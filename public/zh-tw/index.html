說明

分數怎麼算？

每個位址從 100 分開始，依各來源的發現扣分：機房網路最多扣 20，代理標記扣 20，VPN 標記扣 15，Tor 扣 40，濫用回報扣 10，平均詐騙分數最多扣 35，每個郵件黑名單扣 6（最多 24）。標記依同意的來源數折算，只有一個來源標記時只扣一部分。

等級：A 85 分以上，B 70 以上，C 50 以上，D 30 以上，F 低於 30。來源表格下方的明細列出每一項扣了多少。

用了哪些資料來源？

不需要金鑰的：ip-api.com、proxycheck.io、IPQuery、ipapi.is、IP2Location、IPinfo、RDAP（各區域的位址註冊機構）、ip.guide、Shodan InternetDB、Tor 專案的出口清單，以及 Cloudflare（只查本機位址）。站長設定免費 API 金鑰後，還會加上 IPQualityScore、AbuseIPDB、Scamalytics 和 ipdata。每一列都連到該來源自己的查詢頁，可以去核對。

什麼是原生 IP、廣播 IP？

原生 IP 在它註冊的國家使用。廣播 IP 在一個國家註冊（通常是某家機房公司），卻在另一個國家宣告使用。多數定位資料庫依實際位置判斷，但有些服務依註冊地判斷，所以廣播 IP 可能讓你看起來在另一個國家。

這裡比較位址註冊機構的紀錄（RDAP）和多數資料庫給出的位置。註冊紀錄沒有國家時（ARIN 常見），改用該位址段所屬網路的註冊國家。

家用寬頻和機房差在哪？

網站把機房位址視為伺服器、VPN 和代理，而不是真人。串流、售票、銀行和註冊頁面會封鎖它們或要求更多驗證。家用寬頻和行動網路的位址像一般使用者。行動網路的位址還由許多人同時共用（CGNAT），網站很少封鎖。

為什麼各來源的結果不一樣？

每家的資料不同：有的只知道哪些網段屬於機房，有的經營蜜罐或收集客戶的詐騙回報。一台 VPN 伺服器可能已被一家發現，另一家還不知道。所以這裡看有多少來源同意，而不是只信一家。

分數很低怎麼辦？

如果是家裡的寬頻：濫用回報或黑名單紀錄，常代表網路裡有裝置中毒或被當成代理。清理後，向黑名單申請移除（每個黑名單都連到它的查詢和移除頁面）。如果是 VPN 或伺服器，分數主要反映網路類型，無法改變，可以換成提供家用或較少人用位址的業者。

會保存什麼嗎？

每個位址的結果快取 6 小時，避免每次造訪都重複查詢免費的資料來源。除此之外不保存任何東西，IPv4/IPv6 偵測在你的瀏覽器裡完成。
