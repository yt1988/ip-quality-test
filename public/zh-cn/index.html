评分是怎么算的？

每个地址从 100 分开始，按各来源的发现扣分：机房网络最多扣 20，代理标记扣 20，VPN 标记扣 15，Tor 扣 40，滥用报告扣 10，平均欺诈分数最多扣 35，每个邮件黑名单扣 6（最多 24）。标记按多少个来源同意来折算，只有一个来源标记时只扣一部分。

等级：A 85 分以上，B 70 以上，C 50 以上，D 30 以上，F 低于 30。来源表格下方的明细列出了每一项扣了多少。

用了哪些数据来源？

不需要密钥的：ip-api.com、proxycheck.io、IPQuery、ipapi.is、IP2Location、IPinfo、RDAP（各大洲的地址注册机构）、ip.guide、Shodan InternetDB、Tor 项目的出口列表，以及 Cloudflare（只查本机地址）。站长配置免费 API 密钥后，还会加上 IPQualityScore、AbuseIPDB、Scamalytics 和 ipdata。每一行都链接到该来源自己的查询页，可以去核对。

什么是原生 IP，什么是广播 IP？

原生 IP 在它注册的国家使用。广播 IP 在一个国家注册（注册机构的记录里，通常是某家机房公司），却在另一个国家宣告使用。大多数定位数据库按实际位置判断，但有些服务按注册地判断，所以广播 IP 可能让你看起来在另一个国家。

这里比较的是地址注册机构的记录（RDAP）和多数数据库给出的位置。注册记录里没有国家时（ARIN 常见），改用这个地址段所属网络的注册国家。

家宽和机房，区别在哪？

网站把机房地址看作服务器、VPN 和代理，而不是真人。流媒体、票务、银行和注册页面会拦截它们，或者要求更多验证。家宽和移动网络的地址像普通用户。移动网络的地址还由很多人同时共用（CGNAT），网站很少封它。

为什么各来源的结果不一样？

每家的数据不同：有的只知道哪些网段属于机房，有的运营蜜罐或收集客户的欺诈报告。一台 VPN 服务器可能已经被一家发现，另一家还不知道。所以这里看有多少来源同意，而不是只信一家。

分数很低怎么办？

如果是家里的宽带：滥用报告或黑名单记录，往往说明网络里有设备中了病毒或被当作代理。清理之后，向黑名单申请移除（每个黑名单都链接到它的查询和移除页面）。如果是 VPN 或服务器，分数主要反映网络类型，改变不了，可以换提供家宽或较少人用的地址的服务商。

会保存什么吗？

每个地址的结果缓存 6 小时，免得每次访问都重复查询免费的数据来源。除此之外不保存任何东西，IPv4/IPv6 检测在你的浏览器里完成。
