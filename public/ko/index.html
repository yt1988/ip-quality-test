    도움말

    점수는 어떻게 계산하나요?

    모든 주소는 100점에서 시작하고, 출처들이 찾아낸 내용에 따라 점수를 빼요. 데이터센터 네트워크는 최대 20점, 기업 네트워크는 최대 5점, 프록시 표시는 20점, VPN은 15점, Tor는 40점, 악용 신고는 10점, 평균 사기 위험 점수로 최대 35점, 메일 블랙리스트는 하나에 6점(최대 24점)이에요. 표시는 동의한 출처의 비율로 계산해서, 한 곳만 표시했다면 일부만 빠져요.

    사기 위험 점수는 위험 평가 데이터베이스가 IP를 얼마나 의심하는지 0–100으로 나타낸 값이에요. 높을수록 의심스럽다는 뜻이에요.

    등급: 85점 이상 A, 70점 이상 B, 50점 이상 C, 30점 이상 D, 30점 미만 F. 결과 아래에 항목마다 몇 점이 빠졌는지 보여 줘요.

    어떤 데이터 출처를 쓰나요?

    키 없이 쓰는 곳: ip-api.com, proxycheck.io, IPQuery, ipapi.is, IP2Location, IPinfo, RDAP(대륙별 IP 주소 등록 기관), ip.guide, Shodan InternetDB, Tor 프로젝트의 출구 목록, Cloudflare(내 IP만). 사이트 운영자가 무료 API 키를 설정하면 IPQualityScore, AbuseIPDB, Scamalytics, ipdata도 더해져요.

    각 행은 그 출처의 조회 페이지로 연결돼서, 결과를 직접 확인할 수 있어요.

    네이티브 IP와 브로드캐스트 IP가 뭔가요?

    네이티브 IP는 등록된 나라에서 그대로 쓰이는 IP예요. 브로드캐스트 IP는 한 나라에서(주로 데이터센터 업체가) 등록하고, 다른 나라에서 쓰는 IP예요.

    나에게 미치는 영향: 대부분의 위치 데이터베이스는 실제 위치를 보지만, 등록 국가를 보는 서비스도 있어요. 브로드캐스트 IP를 쓰면 그런 서비스는 내가 등록 국가에 있다고 볼 수 있어요. 특정 나라의 스트리밍이나 AI 서비스를 써야 한다면 네이티브 IP가 더 확실해요.

    이 사이트는 지역 등록 기관의 기록(RDAP)과 대부분의 데이터베이스가 알려 주는 위치를 비교해요. 등록 기록에 국가가 없으면(ARIN에서 흔해요) 그 주소 대역을 가진 네트워크의 등록 국가를 써요.

    가정용 IP와 데이터센터 IP, 무엇이 다른가요?

    사이트는 데이터센터 IP를 사람이 아니라 서버, VPN, 프록시로 봐요. 스트리밍, 티켓 예매, 은행, 가입 페이지는 이런 IP를 차단하거나 추가 인증을 요구해요.

    가정용과 모바일 주소는 일반 사용자처럼 보여요. 모바일 주소는 여러 사람이 동시에 함께 쓰기 때문에(통신사 NAT) 차단되는 경우가 드물어요.

    출처마다 결과가 다른 이유는요?

    출처마다 가진 데이터가 달라요. 어떤 곳은 어느 네트워크가 데이터센터인지만 알고, 어떤 곳은 허니팟(미끼 서버)을 운영하거나 고객의 사기 신고를 모아요. 같은 VPN 서버를 한 곳은 이미 알고 다른 곳은 아직 모를 수도 있어요.

    그래서 한 곳만 믿지 않고, 몇 곳이 같은 판단을 했는지를 세요.

    점수가 낮으면 어떻게 하나요?

    집 인터넷이라면: 악용 신고나 블랙리스트 등재는 네트워크 안의 기기가 악성 코드에 감염됐거나 프록시로 쓰이고 있다는 뜻인 경우가 많아요. 기기를 정리한 다음, 블랙리스트에 삭제를 요청하세요(각 블랙리스트의 조회·삭제 페이지로 연결돼 있어요).

    VPN이나 서버라면: 점수는 대부분 네트워크 유형에서 나오고, 직접 바꿀 수 없어요. 가정용 IP나 사용자가 적은 주소를 주는 업체로 바꾸는 게 좋아요.

    저장하는 게 있나요?

    검사하려면 그 주소를 위에 나온 데이터 출처들에 보내요. 몇 곳은 내 브라우저가 직접 물어봐요. 결과는 주소마다 6시간 동안 캐시해서, 방문할 때마다 무료 출처에 다시 묻지 않게 해요. 그 밖에는 아무것도 저장하지 않아요.

    출구 IP를 찾을 때는 내 브라우저가 IP 확인 서비스 몇 곳에 직접 접속해요.

    "실측하기"를 누르면 Cloudflare가 브라우저 정보를 읽어 사람인지 판단해요. 이 사이트는 통과했는지 여부만 받아요.

    '실측: 내 연결'은 이 사이트의 자체 서버에서 측정합니다. 브라우저가 무작위 이름 몇 개를 조회하고 probe.1ms.dog에 한 번 연결합니다. 서버는 어느 DNS 리졸버가 조회했는지와 TCP 핸드셰이크 값만 보며, 결과는 메모리에 2분 동안만 두고 디스크에는 쓰지 않습니다.

    /24 이웃 분석은 이 사이트의 자체 서버가 조회합니다. 확인하는 IP가 속한 /24의 역방향 이름 256개와 몇 가지 공개 목록을 대조할 뿐, /24 안의 어떤 주소에도 연결하지 않습니다. 결과는 서버 메모리에 7일 동안 캐시하며 누가 조회했는지는 기록하지 않습니다.
