ヘルプ

スコアはどう計算していますか？

どのアドレスも 100 点から始まり、ソースが見つけた内容に応じて減点します。データセンターのネットワークは最大 20 点、法人回線は最大 5 点。プロキシ判定は 20 点、VPN は 15 点、Tor は 40 点。迷惑行為の報告は 10 点、不正利用スコアの平均で最大 35 点、メール用ブラックリストは 1 件につき 6 点（最大 24 点）です。判定は同意したソースの割合で数えるので、1 件だけの判定なら減点も一部だけです。

不正利用スコアは、リスク判定のデータベースがその IP をどれくらい怪しいと見ているかを 0〜100 で表したもので、高いほど怪しいという意味です。

ランク：85 点以上が A、70 点以上が B、50 点以上が C、30 点以上が D、30 点未満が F。結果の下に、どの項目で何点引かれたかを表示しています。

どのデータソースを使っていますか？

キーなしで使えるもの：ip-api.com、proxycheck.io、IPQuery、ipapi.is、IP2Location、IPinfo、RDAP（地域ごとの IP アドレス登録機関）、ip.guide、Shodan InternetDB、Tor Project の出口リスト、Cloudflare（自分の IP のみ）。サイト運営者が無料の API キーを設定すれば、IPQualityScore、AbuseIPDB、Scamalytics、ipdata も加わります。

各行からそのソース自身の検索ページに移動できるので、結果を確かめられます。

ネイティブ IP、ブロードキャスト IP とは？

ネイティブ IP は、登録された国でそのまま使われている IP です。ブロードキャスト IP は、ある国で（多くはデータセンター事業者が）登録し、別の国で使っている IP です。

影響：ほとんどの位置情報データベースは実際の場所で判断しますが、登録国で判断するサービスもあります。ブロードキャスト IP だと、そうしたサービスからは登録国にいると見なされることがあります。特定の国の動画配信や AI サービスを使いたいなら、ネイティブ IP のほうが確実です。

このサイトでは、地域の登録機関の記録（RDAP）と、多くのデータベースが示す場所を比べています。登録記録に国がない場合（ARIN でよくあります）は、そのアドレス範囲を持つネットワークの登録国を使います。

家庭用回線とデータセンター、何が違う？

サイトはデータセンターの IP を、人ではなくサーバー・VPN・プロキシとして扱います。動画配信、チケット販売、銀行、登録フォームでは、ブロックされたり追加の確認を求められたりします。

家庭用回線やモバイル回線のアドレスは、普通の利用者に見えます。モバイル回線のアドレスは大勢で同時に共有している（キャリアグレード NAT）ので、ブロックされることはまれです。

ソースによって結果が違うのはなぜ？

ソースごとに持っているデータが違うからです。どのネットワークがデータセンターかだけを知っているところもあれば、おとりのサーバー（ハニーポット）を運用したり、顧客から不正の報告を集めたりしているところもあります。ある VPN サーバーを、一方はもう把握していて、もう一方はまだ知らない、ということもあります。

そのため、どれか 1 つを信じるのではなく、いくつのソースが同じ判定をしているかを数えています。

スコアが低いときは？

自宅の回線の場合：迷惑行為の報告やブラックリストへの掲載は、ネットワーク内の機器がウイルスに感染しているか、プロキシとして使われていることが多いです。機器をきれいにしてから、ブラックリストに削除を申請してください（各ブラックリストの検索・削除ページにリンクしています）。

VPN やサーバーの場合：スコアはほぼ回線の種類で決まり、自分では変えられません。家庭用回線の IP や、利用者の少ない IP を提供している事業者に乗り換えるのが近道です。

何か保存されますか？

調べるために、そのアドレスを上に挙げたデータソースに送ります。いくつかのソースには、あなたのブラウザから直接問い合わせます。結果はアドレスごとに 6 時間キャッシュし、無料のソースに同じ問い合わせを繰り返さないようにしています。それ以外は何も保存しません。

出口 IP を調べるときは、あなたのブラウザがいくつかの IP 確認サービスに直接アクセスします。
