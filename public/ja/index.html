    ヘルプ

    スコアの計算方法は？

    どのアドレスも 100 点から始まり、ソースの結果に応じて減点します。データセンターは最大 20、プロキシ 20、VPN 15、Tor 40、不正報告 10、平均不正スコアで最大 35、メールブラックリスト 1 件につき 6（最大 24）。フラグは同意したソースの割合で数えるので、1 つだけなら一部しか減りません。

    ランク：A 85 以上、B 70 以上、C 50 以上、D 30 以上、F 30 未満。ソース表の下に内訳が出ます。

    どのソースを使っていますか？

    キー不要：ip-api.com、proxycheck.io、IPQuery、ipapi.is、IP2Location、IPinfo、RDAP（地域インターネットレジストリ）、ip.guide、Shodan InternetDB、Tor Project の出口リスト、Cloudflare（自分のアドレスのみ）。サイト運営者が無料 API キーを設定すると IPQualityScore、AbuseIPDB、Scamalytics、ipdata も加わります。各行はそのソース自身のページにリンクしています。

    ネイティブ IP とブロードキャスト IP とは？

    ネイティブ IP は登録された国で使われています。ブロードキャスト IP はある国で登録され（多くはホスティング会社）、別の国から使われています。多くの位置情報データベースは実際の場所を見ますが、登録国で判断するサービスもあり、ブロードキャスト IP では別の国にいるように見えることがあります。

    ここではレジストリの記録（RDAP）と多くのデータベースが示す場所を比べます。記録に国がない場合（ARIN に多い）は、そのブロックを持つネットワークの登録国を使います。

    住宅用とデータセンター、何が違う？

    サイトはデータセンターのアドレスを人ではなくサーバー、VPN、プロキシと見なします。動画配信、チケット、銀行、登録フォームはブロックしたり追加確認を求めたりします。住宅用とモバイルは普通のユーザーに見えます。モバイルは多数で共有（CGNAT）されるため、ブロックはまれです。

    なぜソースごとに結果が違う？

    データの集め方が違います。ホスティング会社のネットワークだけを知るもの、ハニーポットや顧客の不正報告を集めるものなど。ある VPN サーバーを知っているところと、まだ知らないところがあります。だから 1 つを信じるのではなく、いくつが同意するかを数えます。

    スコアが低いときは？

    自宅の回線なら、不正報告やブラックリスト掲載は、ネットワーク内の機器が感染したりプロキシとして使われたりしたサインのことが多いです。対処してから、ブラックリストに削除を申請してください（各リストにリンクあり）。VPN やサーバーなら、スコアはおもにネットワークの種類によるもので変えられません。住宅用や利用者の少ないアドレスを提供する事業者を選びましょう。

    何か保存されますか？

    無料のソースに毎回問い合わせないよう、結果はアドレスごとに 6 時間キャッシュします。それ以外は保存せず、IPv4/IPv6 の判定はブラウザ内で行います。
